Trap Decoder

Re-derive a zkVerify Agent Games Proof Gatekeeper decision from raw task fields. Paste the fields, plus a claimed decision, and the tool re-evaluates the 7 documented trap checks in order, names the first failing check with per-check evidence, and verdicts whether the claimed decision matches.

Honest scope.
  • No chain reads. Nothing is looked up on-chain: no proof, balance, or block height is fetched anywhere.
  • No proof verification. Whether a proof is real, on-chain, or valid is never judged here.
  • Reuse is only as complete as the pasted list. The reuse check compares proof_tx against the seen-list you paste — and nothing else. An empty list means reuse can only pass.
  • Correctness is re-derivation from pasted fields only. Given these field values, this is the decision the documented checks produce. Nothing pasted is stored or sent anywhere except this page's own API.
